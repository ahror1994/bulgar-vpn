# Bulgar VPN

Native iOS + Android VPN client and account API, based on the owner's specification and dark blue/emerald UI references dated 9 September 2026.

**Status: development foundation, NOT a production VPN.** Mobile shells do not tunnel traffic yet. Real server provisioning, payment integration and 2FA are release blockers.

The first implementation is being prepared on a feature branch for review. No credentials or signing identities belong in this repository.
